El proyecto

Este trabajo es para el módulo Entornos de Desarrollo del ciclo de 1.º DAW. Tiene dos objetivos:

  • Aprender a trabajar en equipo con Git y GitHub desde la terminal.
  • Mejorar un programa Java para que sea más limpio y fácil de entender.

Tecnologías que usamos: HTML y CSS para esta web, y Java para el programa.
